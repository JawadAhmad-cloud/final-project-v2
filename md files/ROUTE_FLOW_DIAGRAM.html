🔧 KEY FEATURES & INTEGRATION

  • TCS Shipping: Sellers ship orders and receive tracking numbers via TCS
  • Agenda Scheduler: Automatically updates order status to "delivered" when TCS delivery time arrives
  • Shop Verification: Admin must approve shops before sellers can add products
  • Role-Based Access: Different routes and permissions for Users, Sellers, and Admins
  • Complete Order Pipeline: From shop creation through delivery, reviews, and analytics
  • Inventory Management: Real-time stock tracking and low-stock alerts
📌 Important: The TCS integration in the ship route uses Agenda scheduler to automatically update order status to "delivered" when the scheduled delivery time arrives. This removed the need for the seller order complete route which previously handled TCS updates manually.
